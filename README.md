## About ExtPrint3r

ExtPrint3r is a file that can disable Lightspeed Filter Agent and GoGuardian by loading iFrames. Once you click disable, a set of instructions should appear for you to follow. If you follow the instructions correctly, you should be able to disable the extensions.

It is recommended that you disable the V8 optimizer before using ExtPrint3r. You can do this in the following link. chrome://settings/content/v8
